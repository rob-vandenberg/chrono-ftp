# D-064 Preferences

Topics: [[window]]

(through the Proceed on block FP, 2026-11-12) Settings has pages on the left: General, Panels, Transfers, Queue, Confirmations, Log; every earlier choice moved to its page with its saved value, and an older settings file still loads, each new value at its standard. Confirmations: before closing a tab with unfinished transfers, before deleting, before a dropped file is transferred (the transfer window, or a short question where that window is off). Panels: a double-click on a file opens it or copies it to the other side; the right side can read its folder again every N seconds (off by default, at least 5, never during a drag, one summary line in the session log); a tab can keep its own sort order and columns. Why: the reference program's preferences, as far as they apply here.
