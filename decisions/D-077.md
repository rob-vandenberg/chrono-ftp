# D-077 The history drop-down and the folders above the path

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) Back and Forward have a drop-down arrow listing the last 10 folders each leads to, the nearest first, with full paths; a choice goes there at once, the folders passed on the way moving to the other list as single steps would. Alt+Left and Alt+Right go back and forward; Backspace still goes up. The path field, while typing, has an arrow (and Alt+Down) with the folder shown and every folder above it; a choice opens it. Why: the reference program's history buttons and its path drop-down.
