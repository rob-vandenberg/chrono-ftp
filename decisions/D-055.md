# D-055 The clickable path

Topics: [[window]]

(the owner, through the Proceed on block FH) The path above each side is a row of folder parts: a click on a part opens that folder. A click on the empty part of the row, or Ctrl+L, turns it into a field to type a path; A typed path is read as in the Open folder window: from the folder shown, ~ for the home folder; one that is no folder gives a calm message. Enter goes there, Escape or a click elsewhere in the window returns; another window taking the focus keeps the typing. A click on a part also gives that side the keyboard focus, and so does the end of the typing. The field always starts with the real path of the folder, never a note, and a refresh leaves what is typed alone. The path of the side with the keyboard focus is highlighted; on the right side its hover text names user@host. A long path makes room from the left, and the last folder always stays visible. Why: as in the reference program, a folder higher up is one click away, and the person sees which side the keys act on (OR-21).
