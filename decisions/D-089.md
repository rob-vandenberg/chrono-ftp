# D-089 The Size and Checksum tabs of Properties

Topics: [[actions]], [[window]]

(through the Proceed on block FE, 2026-11-13) Properties has a Size tab and a Checksum tab, on both sides and for several files. Size: Calculate gives the total size of the files, the number of files and of folders, stoppable; on the server one `find` that prints sizes, summed by `awk`, for all folders at once where the shell has them, otherwise by walking the listings. A link counts as a file and is never followed; a folder that can't be read in full gives "at least". Checksum: the algorithms this side computes, the last one chosen first; each calculation on a thread of its own, so none waits for another; Calculate lists the selected files and the files inside the selected folders with their checksums; Copy gives them as the `*sum` tools write them. Why: the reference program's Properties, and `du` counts the folders' own blocks, so an empty folder would show 4 KB and disagree with the walk of the listings.
