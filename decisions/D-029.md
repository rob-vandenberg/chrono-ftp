# D-029 Trusting a server

Topics: [[connections]]

An unknown SSH host key or a certificate that can't be verified is shown with its fingerprint, and only the person accepts it. Accepted ones are kept in `~/.config/chrono-ftp`; a changed key or certificate is refused, and a server that stops offering encryption too. FTP without encryption asks once per server, because the password would travel readable (OR-19).
