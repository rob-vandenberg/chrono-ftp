# D-065 The session log

Topics: [[connections]]

(through the Proceed on block FP, 2026-11-12) Per connection a log of what Chrono FTP asks the server and what it answers, in `$XDG_STATE_HOME/chrono-ftp/logs/` (else `~/.local/state`), off by default, in three levels: Normal, Detailed, Debug. It grows to a chosen size and is then rotated, keeping a chosen number of older logs. Passwords, keys and the text after FTP's PASS are never written, whatever the level, and there is no option to write them (OR-19). A Session Log window per tab shows it live, taking new lines in batches. The automatic refresh writes one summary line; its listing only at Debug. Why: a log tells what went wrong with a server, and must never become a leak.
