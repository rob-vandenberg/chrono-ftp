# D-079 Dragging with the right mouse button

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) A drag made with the right mouse button drops with a small menu: Copy Here, Move Here, Cancel. Between the sides Copy Here is the drop of the left button and Move Here the same with Move ticked (or a question where the transfer window is off); within the server Copy Here copies on the server (greyed with its reason where it can't) and Move Here moves. "Offer Move Here after dragging with the right mouse button" (Settings, Panels, on at first) greys Move Here with its reason. A right-click menu waits until the button comes up, so a press can start a drag; a right-click never opens a file or folder. Dragging with the left button is not changed. Why: the reference program's drop menu, and the owner drags with the left button almost always.
