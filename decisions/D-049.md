# D-049 One large file in parts

Topics: [[transfers]]

(the owner, through the Proceed on block FC) With the option "Split large files over several connections" (off by default), a single file of at least 64 MB on the file by file way goes over up to 4 logins at once, each writing its own ranges into the one part file; it stays one item with one progress and one question. Only downloads (SFTP and FTP) and SFTP uploads are split; FTP uploads and the rsync way are never split. Why: one distant connection is often slower than the line, and a file in parts still arrives whole and continues where it stopped.
