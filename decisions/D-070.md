# D-070 Thumbnails

Topics: [[window]]

(through the Proceed on block FQ, 2026-11-13) Each side has a Thumbnails button, kept per tab: the same file list with tall rows, where an image file in view shows a small picture (64 pixels) instead of its icon, so selection, keys and drag and drop stay exactly as they are. Only files in view are fetched, newest view first, within a size limit (5 MB) and an image mask on the Panels page; one at a time, after the person stops browsing, never while a transfer to that server runs, on the tab's own thread only while it is idle, and a fetch stops at the next block when the person asks the connection anything or its file leaves the view. The tab's thread only reads the bytes; a picture is decoded on a thread of its own. Pictures are kept in memory only; one that can't be shown keeps its icon, while a refusal for now or a broken-off read is tried again later, after a growing wait. Why: the reference program shows thumbnails, and fetching must never slow the person's own work.
