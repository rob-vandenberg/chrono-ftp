# D-080 Pausing the automatic refresh and clearing cached listings

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) The menu of a tab has Pause Automatic Refresh, a switch for that tab only (greyed with its reason while the automatic refresh is off in Settings), and Clear Cached Listings, which forgets the folders the tree of the right side read and reads the folder shown again (greyed while the tab is not live). Why: the reference program's per-session refresh switch and its Clear Caches.
