# D-094 Synchronize may delete, and says so first

Topics: [[actions]]

(through the Proceed on block FF, 2026-11-13) Mirror plans a delete for what the source no longer has. The row is always in the checklist, whatever the box says; "Delete on the other side" decides only whether it starts ticked, as the reference program does, and it is greyed with its reason in both-directions mode and in timestamps-only mode. Apply names how many items will be deleted, says that they can't be brought back, and asks first; a No queues nothing. This changes [[D-038]], which said nothing is ever deleted. Why: a mirror is worth nothing without deleting, and the step that can't be undone is always seen before it happens (G-2). Review round 1: the question names the files and the folders apart, says that a folder is deleted with everything in it, names the files inside where the background count knows them and says plainly where it does not, and names the mask too, since a folder goes whole; it never says less than it does (G-2).
