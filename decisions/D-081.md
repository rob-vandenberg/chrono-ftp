# D-081 One mask engine

Topics: [[window]] [[transfers]]

(through the Proceed on block FD, 2026-11-13) Every mask goes through one engine, `core/masks.py`, with the reference program's syntax: patterns separated by `;` or `,`, a `|` between what is included and what is left out, a trailing `/` for folders, a pattern with a path matching the folder an item is in, and size and date conditions (`>1M`, `>2025-01-01`, `>7D`, `>=today`). Without patterns of its kind before the `|`, everything of that kind is included; an included folder includes the folders inside it. A mask that can't be read gives a calm text that points at the fault, and the field selects it; nothing ever crashes on a mask (OR-15). The file colours ([[D-069]]) and the thumbnail mask ([[D-070]]) ask the same engine and keep their meaning: a pattern names files, one ending in `/` folders. In a transfer the items the person picked always go: the mask decides only what goes from inside a picked folder, and a picked folder is never tested against the folder patterns itself (`deep/` on the picked folder `tree` sends `tree/deep`). Why: one syntax everywhere, as in the reference program, and one place to test; what the person chose by hand is never undone by a mask.
