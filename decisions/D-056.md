# D-056 Bookmarks and location profiles

Topics: [[window]]

(the owner, through the Proceed on block FH) Ctrl+B makes the folder of the focused side a bookmark at once, named after its last folder; Ctrl+O opens a small window with a path field, the paths typed before and the bookmarks of that side. Local bookmarks are shared; a remote one belongs to its connection or, by choice, to all. Each side has a Bookmarks button with a menu. Location profiles are named pairs of a local and a remote folder, optionally in a folder of profiles, opened with one click from Location Profiles on the top bar. One window organizes both: rename, delete, drag into another order, a key per bookmark, which holds Ctrl or Alt or is a free F-key, and is never a key lists and fields use. A folder typed there is read as in the path field. A deleted connection takes its own bookmarks and profiles along. A connection saved under a new name keeps its bookmarks and profiles, also while its tab is open. All is kept in `bookmarks.json` in the settings folder; a damaged file is set aside and never stops the program (OR-15). Why: the reference program has them, and a folder that can't be opened leaves its side calmly where it was (OR-23).
