# D-030 Transfers without rsync

Topics: [[transfers]]

`rsync` runs only with a key login, because it can't use a stored password; with a password, or when `rsync` can't log in, SFTP or FTP takes over. FTP transfers get a login of their own, so browsing goes on. Every transfer lands in a temporary file first, so a stop or failure never touches the file already there; nothing is replaced without asking, and links to folders are not followed.
