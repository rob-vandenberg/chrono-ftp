# D-073 Selection keys, the two-pane selection mode and This File Only

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) Each list has Select All (Ctrl+A, never the parent entry), Invert Selection (Ctrl+I), Clear Selection (Ctrl+Shift+A), Select the Same Extension (of the focused file), Restore the Previous Selection and Mark and Move Down (Insert), all also in a Select submenu of its right-click menu, greyed with their reason. A Settings choice (Panels, off at first) turns on the two-pane selection mode: a click or an arrow key moves the cursor without selecting, Insert or Space marks, Ctrl+click and Shift mark as usual, and an action works on the focused file when nothing is marked, a left-button drag too. The This File Only submenu acts on the file under the cursor and ignores the selection. Why: the reference program's selection actions and its keyboard-driven mode.
