# D-062 My key and my password on the server

Topics: [[actions]], [[connections]]

(the owner, through the Proceed on block FM) The menu of a tab installs my public key on its server: a .pub file is chosen (the connection's own key's .pub first; a comment with any letters is kept exactly), and over SFTP alone ~/.ssh is made with 700 where it is missing, the key is added to authorized_keys only when it is not there yet, a new file gets 600 and rights others could write are put right; the window says each step. It also changes the password on the server: old, new, new again, through the server's own passwd in a terminal of its own, only with a shell over SFTP (greyed without, not shown on FTP, [[D-027]]); on success the stored password is replaced (OR-24), a refusal shows the server's words calmly. No password or key is ever logged, and a password never appears in what is shown. Both are tested only on the fake servers (OR-26). Why: the reference program offers both, and they save a trip to a terminal.
