# D-075 Sizes, natural sort and the column header menu

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) Sizes show as short (1.2 MB, as before; the standard), kilobytes (1,206 KB, rounded up) or bytes (1,234,567), on the Panels page, in the list and the status line alike. Names sort naturally ("file2" before "file10"; a Panels choice, on at first); folders always come first and in the order of their names, whatever column sorts the files. A right-click on a column header sorts up or down by it, hides it (never the name), shows or hides each column, fits the widths, or restores the standard columns; kept with the columns, per tab where Settings keeps the columns per tab. Why: the reference program's size formats, natural order and column menu.
