# D-053 The connections window starts on the last connection

Topics: [[window]]

(the owner, 2026-11-10) The connection that last went live is remembered, and at start the connections window opens on it: selected in its list, in view, its fields shown. Why: the top item of the list is almost never the one a person wants; the last one usually is. When that connection is gone, the window starts as it did before.
