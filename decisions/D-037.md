# D-037 Edit

Topics: [[actions]]

(the owner) Edit opens a server file in the person's own program through a temporary copy, and every save goes back through the transfer queue, without asking. A double click on a server file does the same; on a local file it opens it. Why: it is a button in the owner's picture of the goal. A save that did not reach the server keeps its copy on the disk, a refused send asks to try again, and a rename, move or delete of the file on the server ends the edit once the server agreed.
