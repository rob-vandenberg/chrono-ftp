# D-074 The key set

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) The keys of block FG: F6 moves the selection to the other side (the transfer window opens with Move ticked, or a question comes where that window is off), Shift+F6 moves on the server, Ctrl+F3 to Ctrl+F9 sort by name, extension, date, size, rights, owner and group (the same key again turns the order), Alt+Left and Alt+Right go back and forward, Ctrl+R refreshes the side with the focus next to F5, Ctrl+Shift+C copies the selected names, Ctrl+Alt+H shows or hides hidden files. Settings, General, offers the classic two-pane key set (the standard: Alt+F7 finds files, Ctrl+F4 sorts by extension) or the file manager key set (Ctrl+F finds files, Ctrl+F4 free). Every key is in PROGRAM_KEYS, so no bookmark takes it. Why: the reference program's commander keys, and its choice of a second key set.
