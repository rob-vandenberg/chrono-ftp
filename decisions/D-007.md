# D-007 Colours

Topics: [[window]]

(the owner) A connection can have a background colour the person chooses, on the right side only, both tree and file list; it is off for a new connection. A live connection without a colour looks neutral, like the left side. Not connected is plain grey, and a tab whose connection dropped is grey too. Text is black or white by the brightness of the background, selected rows too (OR-2, OR-3). Why: the folder tree is where the owner got lost, and the owner chooses per connection whether that needs a colour.
