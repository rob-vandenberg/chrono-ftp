# D-007 Colours

Topics: [[window]]

(the owner) Each connection has a background colour the person chooses, on the right side only, both tree and file list. Not connected is plain grey, and a tab whose connection dropped is grey too, so a colour always means a live connection. Text is black or white by the brightness of the background, selected rows too (OR-2, OR-3). Why: the folder tree is where the owner got lost.
