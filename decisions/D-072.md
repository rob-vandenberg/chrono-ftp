# D-072 Type-ahead

Topics: [[window]]

(through the Proceed on block FG, 2026-11-13) Typing in a file list moves the cursor to the first name, from the cursor on and round the end, that starts with what was typed: any case while only small letters are typed, the exact case once a capital is; outside the two-pane mode the found row is the selection. Tab goes to the next match, Shift+Tab to the one before, Backspace takes the last letter back, Escape, a pause of 1.5 seconds, a list filled again or an entry opened starts afresh; a letter that fits nothing beeps and changes nothing. The side's status line shows what was typed. Why: the reference program's panel search, and a field never loses a key to it (OR-21).
