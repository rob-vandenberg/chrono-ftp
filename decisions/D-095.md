# D-095 Apply goes through the queue

Topics: [[transfers]], [[actions]]

(through the Proceed on block FF, 2026-11-13) Apply sends the ticked rows to the queue: every copy is a transfer as any other, without an overwrite question and without "only newer" (the ticks are the decision), and the deletes, the moves on one side and the dates to set go to the queue as items of their own, one per kind and per side. Such an item runs like any other: it can be paused, stopped and watched, its progress counts the steps done, one step that is refused never stops the rest, and it ends by saying how much was done and why the rest was not ([[D-046]], OR-15). Why: the person has one place where everything that changes a server happens, with one set of controls over it. Review round 1: a copy between two folders on this computer replaces the file that is there, as a copy to a server does; only a link in its place is refused, since writing through it would land in another tree.
