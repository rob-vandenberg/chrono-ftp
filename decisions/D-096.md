# D-096 Moved files, and two folders on this computer

Topics: [[actions]], [[window]]

(through the Proceed on block FF, 2026-11-13) A file only on the target plus a file of exactly the same size only on the source becomes one row "Move on the server" in place of a copy and a delete, but only where that size belongs to exactly one file on each side; it starts ticked only when the dates match too, or the checksums where both were computed. The left side's menu also opens the same window for two folders on this computer, which never touches the right side of the main window (OR-1); there the right side reads "the other folder", never "the server". Why: moving a large file on the server instead of sending it again is the whole point, and two folders on this computer are the same job. Review round 1: Reverse has no meaning for a move row (the file is on one side only), so it is greyed with that reason instead of doing nothing (OR-20); Reverse of a delete row copies from the side the file is still on. The owner's review (0.0.44): a sync of two folders on this computer runs with its window on screen, showing what it is doing and how far it is, and can be aborted from its button or by closing the window ([[D-097]]).
