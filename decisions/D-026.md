# D-026 Test elsewhere first

Topics: [[way-of-working]]

(the owner) Connection code is tested with opt-in `live` tests against the owner's test machines; the default run is offline. Everything is tried on a throwaway folder first, never first on a live server or a machine with real backups (OR-26). The four connection types covered: full SSH, SFTP only, encrypted FTP, plain FTP.
