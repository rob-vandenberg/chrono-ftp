# D-001 What Chrono FTP is

Topics: [[program]]

(the owner) A two-pane remote file manager for Linux and a deliberately small subset of the reference program: saved connections, tabs, fast copy with throttling, recursive owner, group and permissions, a terminal, remote search, remote rename, move, copy and delete; maybe compare. Why: the owner relies on the reference program and has none on Linux. Nothing else is added unless the owner asks (OR-13).
