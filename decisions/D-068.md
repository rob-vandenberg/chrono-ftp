# D-068 The licence and the update check

Topics: [[window]]

(through the Proceed on block FP, 2026-11-12) The About window has "Licence", the full AGPL-3.0 text from the project's LICENSE file as shipped (never retyped), and "Check for Updates", which asks GitHub's public API for the version tags of the repository named in `pyproject.toml`, only when pressed, on a thread of its own, with a neutral User-Agent and nothing about the person; it says calmly whether a newer version is there, with a link to its page, and never downloads or installs. Why: the licence must travel with the program, and the person decides when the network is asked.
