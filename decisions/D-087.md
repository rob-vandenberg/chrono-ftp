# D-087 Masks in transfers

Topics: [[transfers]]

(through the Proceed on block FD, 2026-11-13) The transfer settings have a file mask, "Skip hidden files" (names that start with a dot) and "Skip empty folders" (a folder that holds no file that goes, at any depth), all off at first. What they leave out inside a picked folder is neither counted nor sent, and the end of the job says how many items were left out; an item the person picked always goes ([[D-081]]). Where rsync works, a job that leaves out or changes anything is looked over first and rsync gets the exact list of what passes. A save from Edit and the rows ticked in Compare always go exactly as they are. Why: the reference program's include and exclude masks, never leaving anything out in silence.
