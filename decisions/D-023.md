# D-023 No personal detail on GitHub

Topics: [[way-of-working]]

(the owner) No computer name, server, network address or account detail in the project folder or on GitHub; neutral words in the documents, made-up data in tests. No other program's name and no name of the AI assistant reaches GitHub (OR-10, OR-11). `gitpush.sh` scans every outgoing file and the message, and the push guard checks every commit.
