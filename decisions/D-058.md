# D-058 Starting folders

Topics: [[window]], [[connections]]

(the owner, through the Proceed on block FH) A connection has a local starting folder next to the remote one, and a choice "Remember the last folders", off for a new connection; when on, the folders of both sides become its starting folders when its tab or the program closes. A starting folder that is gone gives a calm message and opens the home folder. Older connection files still load; a folder whose name is not valid UTF-8 is stored and read back exactly. Reconnect of a dropped tab logs in with the connection as it is saved now. The reference program's "starting folder required" option is left out. Why: the person starts where the work is, and a missing folder never stops a connection.
