# D-027 Actions that need a shell

Topics: [[actions]]

(the owner) An action that needs a shell is available only on an SFTP connection with a working shell: recursive owner, group and permissions, search on the server, the terminal and the change of the password. On an FTP connection these actions are not shown; on an SFTP connection without a shell they are greyed out. A copy on the server uses the shell, or else the protocol where the server offers it, and is greyed with its reason where neither can ([[D-061]]); the checksum step of compare likewise uses the shell's `*sum` tools, or else SFTP's check-file or FTP's HASH where the server offers them, and is greyed with its reason where none can ([[D-088]]). Where there is no shell, rename, move, delete and rights use the protocol, which is slower. Why: a per-file loop over a whole tree takes an hour or more.
