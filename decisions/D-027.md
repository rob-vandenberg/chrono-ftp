# D-027 Actions that need a shell

Topics: [[actions]]

(the owner) An action that needs a shell is available only on an SFTP connection with a working shell: recursive owner, group and permissions, copy and search on the server, the terminal and the `sha256sum` step of compare. On an FTP connection these actions are not shown; on an SFTP connection without a shell they are greyed out. Where there is no shell, rename, move and delete use the protocol, which is slower. Why: a per-file loop over a whole tree takes an hour or more.
