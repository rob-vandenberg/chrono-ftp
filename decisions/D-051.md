# D-051 One Chrono FTP at a time

Topics: [[window]]

(the owner, 2026-11-10) Only one Chrono FTP runs per user. A second start tells the running one, through a local socket, to come to the front, and ends without a window; a socket left behind by a crash never blocks a start. Connect on a connection that already has a tab never opens a second tab: with changed settings it logs in again in that tab, with the same settings it switches there and reconnects it only when it dropped. Why: one window holds every connection as a tab ([[D-008]]); two copies or two tabs of one connection only confuse.
