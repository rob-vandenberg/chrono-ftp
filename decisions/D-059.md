# D-059 The About window

Topics: [[window]]

(the owner, 2026-11-12) F1 opens "About Chrono FTP": the program icon, "Chrono FTP version x.y.z", "An open-source file transfer program for Linux." and "License: AGPL-3.0", with Close; Enter and Escape close it too. The version is read from `pyproject.toml` in a source copy, else from the installed package, never typed in by hand. The title bar of the main window shows the version too: "Chrono FTP 0.0.36"; message boxes keep the program's name. Why: the same About window as the other Chrono programs; it is FP's About window, done ahead of its block.
