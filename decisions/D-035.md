# D-035 Leftovers of a dropped transfer

Topics: [[transfers]]

(the owner, 2026-11-10) Showing a folder tidies what a dropped connection left there, unless a transfer of this connection is running. Only what carries our own suffix and our own note on this computer is touched; a file that merely carries the suffix is someone's and stays. An old file without a file under its real name gets that name back, because it is the only copy; next to the new file it is deleted. A part file, and rsync's folder of unfinished copies, goes when nothing can continue it any more and it is untouched for an hour, so a transfer from another computer is left alone ([[D-044]]). Why: nothing else ever removes them.
