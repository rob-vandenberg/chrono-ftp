# D-035 Leftovers of a dropped transfer

Topics: [[transfers]]

Showing a folder tidies what a dropped connection left there, unless a transfer of this connection is running. An old file without a file under its real name gets that name back, because it is the only copy; next to the new file it is deleted. A part file goes when it is untouched for an hour, so a transfer from another computer is left alone. Only our own suffixes are touched. Why: nothing else ever removes them.
