# D-082 Text mode

Topics: [[transfers]]

(through the Proceed on block FD, 2026-11-13) A transfer is binary (the standard), text, or automatic by a text mask. A text file arrives with the line endings of the side it goes to: one LF per line on this computer and on a server; CRLF and LF both count as a line end in the source, a lone CR and every other byte stay as they are; "Remove the BOM" drops the UTF-8 mark at its very start. The conversion is done by Chrono FTP on this computer, in a file of its own, and the transfer itself stays byte for byte, so the size that arrived is checked exactly and a move removes its source only after the whole converted copy arrived. A text file always goes whole: never continued, split or appended (greyed with the reason), and beside rsync it goes file by file. Why: the reference program's text mode, without ever risking a half-converted file under a real name ([[D-044]]).
