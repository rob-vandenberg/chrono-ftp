# D-090 Folder sizes in the file list

Topics: [[window]]

(through the Proceed on block FE, 2026-11-13) Shift+Space, or Calculate Folder Sizes in the right-click menu, counts the selected folders of the side with the focus into the Size column, as the Size tab counts them ([[D-089]]). It runs in the background on a thread of its own per side, over the tab's own connection, so the person's own actions never wait for it; a count belongs to its tab and its folder: closing that tab or showing another stops it silently, and Stop Counting shows only for the tab shown; while a name is being typed, Shift+Space types a space into it; Stop Counting in the status bar ends it, and so does another folder on that side. A folder that can't be read in full shows "at least …". The sizes stay while the same folder shows. otherwise Shift+Space neither types nor marks; greyed with its reason where no folder is chosen or the connection is not live. Why: the reference program's folder sizes in the list.
