# D-066 Server information

Topics: [[connections]]

(through the Proceed on block FP, 2026-11-12) "Server Information…" in the menu of a tab shows the protocol and its version, the server's software, the encryption (cipher, MAC, key exchange), the host key fingerprint or the TLS certificate, what the connection can do as plain yes and no ([[D-016]]), and the free space in the folder shown: SFTP's statvfs@openssh.com where offered, else `df` where a shell has it, FTP's AVBL where FEAT names it; "unknown" where it can't be known. Read on the tab's own thread. Why: the person can see what a server is and does before trusting it with work.
