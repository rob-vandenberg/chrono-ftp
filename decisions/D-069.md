# D-069 File colours by mask

Topics: [[window]]

(through the Proceed on block FQ, 2026-11-13) The Colours page of Settings holds a list of rules, each a mask such as `*.log; *.tmp` with a text colour and/or a background the person picks; the first rule that fits colours that row's text and background on both sides, a plain pattern for files, one ending in `/` for folders, case not mattering. On the right a rule colours only its own row, the connection's colour stays the rest, and file colours show only while the connection is live, so a colour on the right still always means a live connection ([[D-007]]); a selected row shows the selection's colours over the rule. Why: the reference program colours files by mask, and the meanings of left, right and a live colour must stay ([[D-006]]).
