# D-057 Synchronized browsing

Topics: [[window]]

(the owner, through the Proceed on block FH) Sync Browsing on the top bar is a toggle per tab, greyed while the tab is not connected. While it is on, a step on one side is made the same on the other: as many folders up as the step went up, then down into the folders it added. A folder missing on the other side is made after a question, only that one folder and only when its parent is there; No turns the toggle off. When more than that folder is missing, the toggle turns off at once and names the missing folder. A lost or closed connection, or a new login, turns it off too; it is never turned on again by itself. When the other side can't make the step, the toggle turns itself off and says why. Folders opened by the program itself (a location profile, Ctrl+.) and a move up because a folder went away are no step. Ctrl+. opens the folder of the focused side on the other side; when it is not there, a calm message and nothing moves. Why: the reference program works this way, and a mismatch must never go on silently.
