# D-083 File name conversion

Topics: [[transfers]]

(through the Proceed on block FD, 2026-11-13) A transfer can change the case of the names it writes (unchanged, lower, upper, first letter upper) and replace the characters other systems can't hold (`\ : * ? " < > |` and control characters) by `%XX`; both are off at first and hold for files and folders, both ways. A file that was there before the transfer follows the normal overwrite rules. Two items of the same transfer whose names become one never write over each other, whatever the question setting: the later one is left out, its source stays (also on a move, also beside rsync), and the end of the job names it calmly; only a name the person gives in the question's Rename may take such a place. An item whose name changes, and everything inside a folder whose name changes, goes file by file instead of rsync. Why: the reference program's file name conversion, with the target as Linux sees it and a memory stick or a Windows share in mind.
