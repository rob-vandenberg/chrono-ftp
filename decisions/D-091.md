# D-091 The directions and modes of Synchronize

Topics: [[actions]]

(through the Proceed on block FF, 2026-11-13) Synchronize has a direction (to the server, to this computer, or both ways) and a mode. Synchronize copies what is new or newer and never undoes a newer file on the target; Mirror makes the target an exact copy, so a newer file on the target is replaced too and what the source no longer has is deleted ([[D-094]]); Timestamps only gives files of the same size the source's date without copying them, and is greyed with its reason where the connection can't set a date on the server ([[D-016]], OR-20). The direction starts from the side that has the keyboard focus, and every choice is kept for next time. Why: the reference program's three modes, and the person must never be surprised by what Apply does ([[D-038]]). The owner's review (0.0.44): in a window about two folders on this computer the direction reads "To the other folder", never "To the server" (OR-1).
