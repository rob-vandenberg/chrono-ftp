# D-045 The overwrite question

Topics: [[transfers]]

(the owner, through the Proceed on the changelist of block FB) A file that is there already is asked about, with the size and date of both: Yes, No, Yes to all, No to all, Only if newer, Rename, Append, Resume or Stop, No being the default and closing the question being Stop. An answer holds only for the file as the person saw it: Replace and Append look again right before they act, also on the rsync way and after it, and a file that changed meanwhile is left as it is and said so; "Only new and updated" is a hard rule that no answer for all overrides, and a version saved in the very last moment before a replace is kept aside and named. Why: nothing the person did not see is ever replaced.
