# D-098 Tab extras

Topics: [[window]]

(through the Proceed on block FI, 2026-11-13) A tab can be dragged to another place in the row, and that order is kept: a connection opened again gets its tab back in the place it was dragged to, and one that was never dragged goes at the end. The middle mouse button closes a tab, asking the same question about unfinished transfers as the cross does. Files dragged from the left side or from a file manager can be let go on a tab: they go to that connection's folder on the server and the tab shown does not change; while they are over it the tab is drawn with a clear border and the status bar says where they would go, and a tab that can't take them (not connected, no folder open) is never marked and says why. Ctrl+Tab and Ctrl+Shift+Tab walk the tabs, Alt+1 to Alt+9 jump to one. The menu of a tab also holds Rename Tab…, Duplicate Tab, Reconnect, Disconnect and Close Tab, each greyed with its reason where it can't act (OR-20); a renamed tab keeps its name with its connection, and an empty name brings the connection's own name back. Duplicate Tab makes a second tab to the same server, with the folders the first one is in and its own two folders from then on (OR-4); Connect on that connection still never opens a tab of its own and switches to the first one ([[D-051]]). The button All Tabs next to New Tab lists every open tab. A tab shows the last part of the folder it is in next to its name, and its hover text names both its folders, so two tabs on one server can be told apart. Why: the reference program's tab handling, and a person who never read a manual must see which tab is which and which one would take what they drag.
