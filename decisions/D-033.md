# D-033 One file list on both sides

Topics: [[window]]

The two sides share one list (`ui/filelist.py`), with its own model of rows. The left side reads folders with `os`, not with a Qt model, and its folder tree stays a Qt model. Why: sorting, the parent entry on top, drag and drop and the count line then work the same on both sides, and a Qt model hides names that are not valid UTF-8.
