# D-022 Server work and layers

Topics: [[way-of-working]]

Anything that touches a server stays outside the window code, in `connections` and `transfers`, so it can be tested without a screen; pure window actions stay in the window. Layers are enforced by import-linter and only `ui` imports PySide6 (OR-17). There is no separate command-line program, because the scope has none and end-user tasks are graphical (OR-25).
